# NST-ArtFusion

This repository reproduces the neural style transfer method of Gatys et al. (2016) with several enhancements.

The original Gatys et al. (2015) NST implementation using VGG19 is available in classical_VGG19.py.

The improved NST version based on EfficientNet is implemented in main.py.

A tested Jupyter notebook demonstrating the architecture can be found at src/exp/architecture.ipynb.
